# 机器学习 / 深度学习基础概念（第 2 周笔记）

## 1. 监督学习
- 一句话：给模型「输入 + 标准答案」让它学规律，之后遇到新输入也能接近正确答案。
- 例子：给 6 万张手写数字图片和答案，模型学会「看图识数字」。
- 对比：无监督学习没答案；强化学习靠奖励惩罚。

## 2. 损失函数
- 一句话：衡量「模型错得多离谱」的尺子，训练目标就是让它越小越好。
- 例子：模型说「70% 是 7」而真实是 7 → 损失小；说「90% 是 2」→ 损失大。
- 分类常用交叉熵（CrossEntropy），回归常用均方误差（MSE）。

## 3. 梯度下降
- 一句话：沿「损失下降最快的方向」一步步调参数，像下山一样走到谷底。
- 关键：学习率决定每步多大；太大震荡、太小太慢。
- 常用：SGD、Adam（新手用 Adam）。

## 4. 训练 / 验证 / 测试划分
- 训练集：让模型学；验证集：调超参、选模型；测试集：最后只测一次。
- 目的：防止拿「考试题」当练习题，成绩虚高。

## 5. 过拟合
- 一句话：模型背下了训练集，而不是学会规律，换新题就崩。
- 表现：训练损失很小、验证/测试损失很大。
- 对策：更多数据、正则化、Dropout、早停。

## 6. 评价指标
- 分类：准确率、精确率/召回率、混淆矩阵。
- 回归：MAE、MSE。
- 检测/位置：IoU、mAP。
- 注意：损失函数用于训练优化，评价指标用于最后汇报，两者可不同。
