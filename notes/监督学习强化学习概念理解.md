贯穿例子：识别图片里的手写数字（0~9）。输入是一张 28×28 的图片，输出是「这是哪个数字」。
1. 监督学习
一句话：给你「题目 + 标准答案」让你学规律，之后遇到新题目也能答对。
• 输入 x = 图片，标签 y = 正确答案（比如「7」）。
• 模型学一个函数 f：输入图片 → 输出预测。
• 对比：无监督学习没有标准答案（只给一堆图片让你自己找规律）；强化学习靠「奖励/惩罚」学，而不是靠标准答案。
2. 损失函数
一句话：衡量「模型错得有多离谱」的尺子，我们想让这个数越小越好。
• 模型输出「70% 是 7，20% 是 3，10% 是 5」，正确答案是 7 → 错得不多，损失小。
• 模型输出「90% 是 2」，正确答案是 7 → 错得离谱，损失大。
• 分类常用交叉熵（CrossEntropy），回归（预测连续值，比如位置坐标、房价）常用均方误差（MSE）。
3. 梯度下降
一句话：怎么一步步把损失「调小」的算法。
• 想象你站在山上（损失大），想走到谷底（损失最小）。
• 梯度告诉你「哪个方向最陡」，你就沿反方向迈一步。
• 学习率 = 每步迈多大：太大容易冲过头，太小走得慢。
• 常用优化器：SGD、Adam（Adam 会自动调整步长，新手先用它）。

为什么要分：如果拿「考试题」来练习，考得再好也不代表真会。测试集就是「从没见过的考试」，只测一次才公平。
5. 过拟合
一句话：模型把训练集「背下来了」，而不是学会了规律，导致换新题就崩。
• 表现：训练集损失很小，验证/测试集损失很大。
• 就像考试前只背了原题，换个数字就不会了。
• 对策：更多数据、正则化、Dropout、早停（Early Stopping）。
6. 评价指标
一句话：怎么客观地给模型「打分」。
• 分类：准确率（accuracy）、精确率/召回率（precision/recall）、混淆矩阵。
• 回归（比如预测目标位置）：平均绝对误差（MAE）、均方误差（MSE）。
• 检测/位置：IoU（预测框和真实框重合多少）、mAP。
记住一句话：损失函数是训练时用来「优化」的，评价指标是训练完用来「汇报好坏」的，两者可以不同。
